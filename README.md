# Evalion — Smart MCQ Exam Platform

Evalion is a web-based MCQ examination platform designed to help students attend and practice timed tests in a structured, exam-like environment.

The platform was built for real use among classmates, focusing on fairness, usability, and ease of administration.

---

## 🚀 Features

- Timed MCQ examinations
- Tab-switch detection to discourage malpractice
- Student registration and authentication
- Admin-controlled exam creation and score release
- Excel-based question uploads
- Automated scorecard generation
- Clean and responsive student-friendly UI

## 🧑‍💻 Running the Project Locally

### Prerequisites
- Node.js & npm  
  (Recommended: install via nvm — https://github.com/nvm-sh/nvm)

### Setup

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
```
